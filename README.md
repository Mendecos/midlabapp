# Sistema de Controle de Empréstimos

Aplicação web desenvolvida para auxiliar no controle de empréstimos de equipamentos e materiais em instituições educacionais.

## Funcionalidades

* Login de usuário
* Cadastro de empréstimos
* Visualização dinâmica em cards
* Pesquisa de registros
* Exclusão de empréstimos
* Persistência de dados utilizando Local Storage
* Exportação de registros para CSV
* Compatibilidade com Microsoft Excel

## Tecnologias

* Next.js
* React
* TypeScript
* Tailwind CSS

## Objetivo

O projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento Front-End moderno, incluindo gerenciamento de estado, componentização, manipulação de dados, armazenamento local e exportação de informações em formato tabular.
